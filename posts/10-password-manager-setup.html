Password Manager Setup Walkthrough

Reusing passwords is risky because a breach at any one of your accounts effectively hands over the keys to every other account using the same password. A password manager solves this by generating and storing a unique, strong password for every site, so you only need to remember one master password.

To get started: install a reputable password manager (Bitwarden and 1Password are both well-regarded; Bitwarden has a solid free tier). Create one strong, memorable master password — this is the only one you'll need to remember, so make it long and unique, ideally a passphrase of several random words.

Then, as you log into sites over the next few weeks, let the manager save and eventually replace each existing password with a randomly generated one. Most managers also include a built-in check that flags any of your saved passwords that have appeared in known data breaches.

Key takeaway: you don't need to change every password overnight. Install the manager, turn on MFA on the account itself, and let it gradually take over as you naturally log into things.
